# 宏观补充 01：美国经济的运行、全球传导与重要日历｜重建版

> 根据聊天记录重建，2026-11-04（UTC+8）。不是旧工作区原件，不宣称逐字一致。本章解释机制，不提供当日美国经济诊断或实时选举结果。频率和时间为常规安排，未逐日核验近期日历，实际日期以发布机构为准。建议先读宏观补充 00。

## 1. 六组主体与基本循环

- 居民：工作、收入、消费、储蓄与负债。
- 企业：订单、生产、定价、投资、招聘和利润。
- 政府国会：税、转移支付、采购、投资、监管和融资授权。
- 美联储：政策利率、资产负债表、流动性工具与沟通。
- 银行资本市场：融资成本、信用可得性、财富和风险承受。
- 海外：进出口、汇率、美元融资、资本与供应链。

最简单的循环：居民花钱 → 企业收入 → 招聘、工资和投资 → 居民收入 → 再消费。

价格、利率、信用、政策和预期决定循环强弱。美国居民消费长期大致占 GDP 七成上下，因此就业收入很重要；但边际变化也可能由 AI 投资、财政、住房等主导。

美国 GDP 统计境内生产，上市公司可从全球赚钱，股指还可能集中于少数行业。美国经济和美股不能直接画等号。

## 2. 八组因素

### 2.1 需求与增长：钱花在哪里

GDP 支出法：消费 C + 投资 I + 政府购买 G + 净出口 NX。

拆商品服务、必需可选、收入阶层；企业投资拆设备、厂房、软件、知识产权与库存；住宅投资看新建等生产，旧房总成交额并非全部新增 GDP；转移支付先影响居民收入，不全部直接算政府购买。

进口扣除是剔除消费投资等中的境外生产，不能只看负号就判断进口设备投资伤害经济。

问题不只消费强不强，还要问来源：工资、退税、财富效应、借贷或消耗储蓄，持续性不同。

### 2.2 就业收入：消费基础与成本线索

订单 → 工时/招聘 → 劳动收入 → 消费，但企业也可能先提效率或用 AI，不立即增加雇员。低招聘与低裁员可同时出现。

看招聘、裁员、工时、工资、劳动参与和行业广度。失业率受劳动供给影响，退出找工也可使其下降。

### 2.3 通胀：需求、供给与预期

需求超供给、能源运输、关税、劳动力、住房服务、汇率与预期都可能推动价格。工资是重要机制，不是唯一必要条件。

价格水平与通胀速度不同：从 4%降至 2%是涨慢了，不是价格回到过去。一次性涨价是否持续，要查成本传导、购买力、反复冲击和预期。

### 2.4 美联储与利率

双重使命为最大就业与价格稳定，长期通胀目标以 PCE 指数衡量为 2%。政策还评估趋势、金融风险和预期。

加息通过住房、消费信贷、企业融资、估值、汇率与金融条件影响需求，有滞后且部门不同。降息必须区分预防性调整和已陷衰退后的应对。

四种利率要分开：政策短端；美债市场收益率；实际收益率；居民企业含信用等溢价的融资利率。美联储降息不保证十年收益率下降，也不保证银行放松贷款。

### 2.5 财政、国债与政治

减税、补贴、转移、采购和投资可支持需求，效果依对象、期限和状态。区分赤字水平与边际变化、提案与落地、短期需求与长期供给、国债融资与央行购债。

高债务与付息约束选择，但不自动等于危机或必然降息。看名义增长、有效利率、期限、税收、融资与信心。财政扩张可同时支持利润、抬高通胀和债券供给。

### 2.6 信用、金融条件与资产负债表

即使政策利率不变，市场利率、信用利差、股票和贷款标准也会改变融资环境。价格和可得性都要看，贷款少可能是供给不愿贷或需求不想借。

股房上涨可形成财富效应，但持有资产与消费倾向分布不同，富裕家庭改善不代表所有居民。

### 2.7 供给、生产率与技术

人口移民、参与率、资本、能源、基础设施和技术决定生产能力。生产率提高有利于增长而不过度推高成本，但早期建设也会增加资金、电力、设备与人才需求。

AI 短中期看资本开支、设备进口、电力建设、融资与折旧；长期看技术扩散、单位成本和全经济效率。投入增加不等于生产率已经兑现，也不保证相关股票回报。

### 2.8 贸易、汇率与外部冲击

关税成本可能由海外供应商、进口商、消费者分担。美元影响进口成本、海外收入、出口竞争和全球融资；它是相对价格，不能只看美国一边。

战争能源冲击可让增长与通胀向不利方向同时变化，简单的强就加息、弱就降息会失效。

## 3. 五条反馈链

### 3.1 需求与通胀

收入/财政支持 → 订单消费 → 用工投资 → 供给跟不上时涨价 → 政策可能更紧 → 需求降温。若效率同步改善，增长可较强而通胀不加速。

### 3.2 利率与住房

按揭贵 → 购房建房弱 → 家具家电等受影响。但美国存量固定利率贷款未必立刻重定价，低息持有人不愿搬家会减少供应，成交弱与价格坚挺可并存。

### 3.3 资产与财富

股票涨 → 部分家庭财富和企业融资改善 → 消费投资 → 盈利；反向也可成立。美联储不以保障股市上涨为使命，所谓政策看跌期权不是承诺。

### 3.4 财政债务与利率

财政扩张 → 需求收入支持；融资需求可能增加 → 供给及通胀/期限补偿影响长端 → 再融资逐步加重付息 → 约束未来财政。

不是自动爆炸：增长税收、期限、需求和政策能改变结果；一次加息不会让全部债务立即重定价。

### 3.5 信用收缩

损失违约 → 融资收紧 → 投资招聘消费减少 → 收入利润弱 → 损失增。需看利差、贷款标准、拖欠和融资可得性，不只政策利率。

## 4. 为什么好数据可以让股票下跌

市场同时看盈利、折现率、风险溢价与事前预期。

| 背景 | 强就业的可能含义 |
|---|---|
| 通胀黏性高 | 需求难降温、降息推迟，估值可能承压 |
| 通胀回落但恐衰退 | 软着陆与盈利更稳，可能利好股票 |
| 总量强但工时广度弱 | 结构性强，不代表全体居民改善 |

弱就业可能利好降息预期，也可能恶化盈利信用。不能只背“坏消息是好消息”。

每次比较：对预期、对修订后的前值、结构与广度、增长通胀政策含义、股债汇商品同窗口反馈。还要考虑误差范围和样本噪声。

## 5. 美国影响全球的七个渠道

1. **贸易订单**：消费和投资改变进口与全球供应链，中转不等于最终需求，商品服务进口含量不同。
2. **美元融资**：利率、美元和风险偏好影响外部偿债，尤其本币收入美元负债；套保、美元收入和储备决定脆弱性。
3. **利率估值**：美债改变相对吸引力和折现，盈利及风险溢价可抵消。
4. **汇率政策空间**：资本流动和进口成本形成约束，但不要求各国同步跟随美联储。
5. **商品**：美元需求影响价格，供给、战争、天气可占主导；金铜油不同。
6. **技术资本开支**：美国企业预算影响全球芯片、光通信、设备与电力订单；利润归属随采购与竞争变化。
7. **贸易产业政策**：关税、补贴、出口限制、审查与标准改变竞争；表态、立法、司法和执行分别记录。

对中国同时看外需、人民币、国内信用与政策。美国总体不强而部分出口高景气可以共存；景气强也不保证股票估值合理。

## 6. 核心指标表

| 主题 | 报告指标 | 主要读法与边界 |
|---|---|---|
| 就业 | 非农新增 | 企业调查岗位变化、行业、修订；不等于去重的所有就业人数 |
| 就业 | 失业率 U-3 | 家庭调查失业/劳动力；参与变化会影响 |
| 就业 | 参与率、就业人口比 | 查退出进入、老龄化、移民与样本 |
| 收入 | 时薪、工时 | 收入成本与用工，平均工资受行业结构影响 |
| 就业 | 初请续请 | 周频裁员与持续找工，单周噪声大 |
| 就业 | JOLTS | 空缺、招聘、离职；空缺非实际雇用 |
| 工资 | ECI | 季度工资福利成本，结构更可比但滞后 |
| 物价 | CPI | 总体核心、商品住房服务、趋势和广度 |
| 物价 | PCE | 美联储目标口径，与 CPI 权重覆盖不同，可修订 |
| 成本 | PPI | 上游线索，不必同幅传至 CPI |
| 消费 | 实际 PCE、收入、储蓄 | 消费是否有收入支持，名义与实际分开 |
| 消费 | 零售销售 | 商品及部分餐饮名义需求，不覆盖全部服务 |
| 企业 | ISM 制造/服务 | 订单就业价格等，扩散指数非同比增速 |
| 生产 | 工业生产、利用率 | 实际生产与供给，范围有限 |
| 投资 | 耐用品/核心资本品 | 设备线索，飞机大单噪声，软件覆盖有限 |
| 房屋 | 开工、许可、销售、价格 | 利率敏感、结构和供应，量价可背离 |
| 总量 | GDP、国内最终需求 | 库存净出口、实际名义、初值修订和年化 |
| 利率 | 2/10/30 年、TIPS | 路径、期限、通胀补偿；倒挂非固定衰退倒计时 |
| 信用 | 利差、SLOOS | 融资难易，降息不保证信贷宽 |
| 财政 | 收支、发行、拍卖、付息 | 力度和需求，单次拍卖不足证危机 |
| 效率 | 生产率、单位劳动成本 | 季度噪声与修订，不只看单季 |

### 6.1 非农到底是什么

BLS《就业形势报告》含两套调查：企业调查给工资就业、工时与时薪；家庭调查给失业率与参与等。对象方法不同，短期背离不自动说明数据失真。

一次非农至少看：新增、前两月修订、失业率、参与率、时薪、工时、行业。不能只读标题。

### 6.2 通胀怎么读

总体核心 → 月环比及数月趋势 → 同比基数 → 商品住房其他服务 → 广度 → 供需工资解释。核心 CPI 回落不等于 PCE 目标已达。短期环比年化需说明复利和季调，不能当无误差预测。

### 7.3 美联储四层信息

- FOMC 决定和声明：决定、投票、措辞与事前定价。
- SEP/点阵图：通常 3/6/9/12 月会议，参与者条件预测，不是承诺。
- 主席发布会：政策门槛、风险与反应函数，需与声明同读。
- 纪要、证词、个人讲话：纪要通常约三周后发布；个人观点非委员会决定。

FOMC 通常一年八次例会，常规声明 14:00、发布会 14:30 美东，临时行动可不同。讲话看谁、是否投票、是否新信息、是否假设条件及口径变化。地方联储投票轮换，不代表非投票人无信息。

Jackson Hole 通常 8 月，可能讨论框架，不是必然改息会议。证词也不是固定买卖信号。

### 7.4 政治、财政与选举

- 中期选举：总统任期中段，众议院全体、参议院约三分之一席位改选。2026 年法定联邦选举日为美国当地 11 月 3 日；亚洲次日进入主要计票观察，结果未必立即清楚。本章无实时结果。
- 总统大选：四年一次，影响任命与政策，很多变化仍需国会、预算与执行。
- 财政年：10 月 1 日至次年 9 月 30 日，拨款截止可能产生停摆风险，不是每年必停。
- 债务上限：没有固定年度 X 日，不能与停摆混同。
- 季度融资和拍卖：看规模、期限与需求，是持续日历。
- 预算税法、关税监管：提案、通过、签署、生效、执行分开。

选举影响：结果对预期的偏离 → 可执行政策概率 → 税支出监管贸易 → 盈利通胀利率与风险。某党赢必涨、选前必涨或总统能保证不衰退，都不是规律。

### 7.5 没有固定日期的风险

银行、战争、制裁、供应和天气冲击需事件复核。财报及资本开支指引连接产业，日历外风险不等于不存在。

## 8. 不同期限做不同判断

| 期限 | 任务 | 证据 |
|---|---|---|
| 小时至几周 | 新信息与预期差 | 公布、讲话、金融价格、初请 |
| 月至季度 | 趋势和政策传导 | 收入消费通胀信用、投资财报 |
| 年至数年 | 供给、资产负债表、制度 | 生产率、人口、债务、技术与贸易 |

长期逻辑不保证短期价格，一根 K 线也不独立推翻长期机制。看好 AI 生产率可以同时担心短期投入侵蚀现金流；关注美国债务不等于明天长债必跌。

## 9. 美国宏观复核八问

1. 消费投资政府外需谁在拉动？实际还是名义？
2. 招聘裁员、工资工时能否支持消费？
3. 通胀改善或反复来自哪里？
4. 美联储与财政收放如何，宣布与执行是否一致？
5. 信用价格与可得性、传染风险如何？
6. 能源人口资本技术何时缓解供给约束？
7. 市场已计价什么，哪些消息不再推动价格？
8. 通过订单美元利率商品科技和政策影响全球谁？

每问附证据和反方解释，结尾写基准/改善/恶化情景、两项最重要反证与下一次复核。每周有数据不代表每周必须交易。
