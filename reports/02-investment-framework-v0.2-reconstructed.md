## 2. 全体系的中心：以组合为决策单位

归纳：宏观观点通过工具和仓位才能转化成结果。方向正确，也可能因工具、杠杆、期限、融资或波动承受力而失败。

完整顺序：

> 资金用途和负债 → 风险承受能力 → 战略框架 → 宏观产业证据 → 核心/卫星分类 → 工具估值 → 组合边际贡献 → 仓位退出 → 复核记录。

D§170—191、321—338 强调绝对收益、避免重大回撤、长期生存和尾部风险。D§176 提到战略稳定性至少占 70%，但未说清按本金、名义敞口还是风险预算计，不可直接生成用户配置。

## 3. 战略/战术与核心/卫星是两条轴

| 分类 | 主要回答 | 不应混同 |
|---|---|---|
| 战略/战术 | 持有目的、期限和调整频率 | 战略不必等于某一行业，战术不等于一定短炒 |
| 核心/卫星 | 经营稳定性、周期性、风险定位 | 长期主题也可能只能以卫星仓位表达 |

## 4. 分散、风险贡献与再平衡

### 4.1 新增资产看边际贡献

D§24—29、179—191 强调新增资产对组合波动的影响，以及不同地区、行业、现金流来源的分散。

补充：

> 预期组合收益 = Σ 权重 × 预期资产收益。
>
> 组合方差 = wᵀΣw。

协方差需同币种、频率、时期与收益口径。低相关可改善某些组合风险收益，但不保证不降低回报；相关性与预期收益会变。低波也可能来自价格平滑或流动性不足。

### 4.2 高波低配不是完整风险平价

D§185—191、337—338 关注单标的、同主题和整体 beta 三级风险。多只小仓 AI 股票仍可能是一个集中押注。

可研究波动风险贡献：RCᵢ = wᵢ(Σw)ᵢ / σ组合。它考虑相关性，不等于单独计算各资产 VaR 再相加。需要同时管理币种、久期、信用、流动性与尾部。

### 4.3 三种不同的调整

1. 定期复核：到月末/季末重新评估，不必交易。
2. 权重再平衡：价格变化导致偏离目标带，按规则恢复。
3. 目标调整：基本面、负债或风险能力改变，修改目标本身。

D§29—31 给出半年与股票涨跌 30%等示例，D§159 讨论上涨后调回目标。价格涨跌阈值不等于权重偏离阈值；需明确分母、成本和税费。

### 4.4 杠杆与资金占用

D§85—116、429、499 的历史记录出现总名义仓位约 170%、债券超过 100%及期货资金占用。

这些必须拆成净资产、保证金、名义本金、总/净敞口、融资成本、抵押品、久期/DV01、期权敏感度和压力损失。保证金小不是风险小；不能照抄历史杠杆。

## 5. 三套宏观模型及长期供给

D§404、406—408 的外部模型图片包括：

### 5.1 增长—通胀

复苏、过热、滞胀、衰退提供环境分类，帮助研究股票、商品、债券、现金的收益来源。不能硬编码固定排序。要明确“高低”还是“上行下行”、同比或环比、趋势偏离及修订。

### 5.2 货币—信用

宽紧货币与宽紧信用组成四象限，关注银行体系资金是否转化为实体需求。M2 与社融只能是粗略代理。

M2 不是央行基础货币发行量，社融不等于银行贷款或企业投资意愿。补看政策/市场利率、政府融资、居民和企业贷款、信贷标准与需求。融资少可能因需求不足，也可能因供给限制。

### 5.3 债务与资产负债表

健康、扩张、泡沫、危机、萧条与债务处理构成解释框架，涉及紧缩、货币化、重组与分配。它解释刺激不一定有效，但不是固定阶段时间表。居民、企业、政府可以处于不同阶段；本外币、期限、利率和偿债能力更重要。

组合使用：增长通胀描述环境 → 货币信用查传导 → 资产负债表查持续性。

D§880 的美国科技、财政、信用周期提醒技术影响资本需求、生产率、税收和政策空间。康波等长期周期是解释性假说，不是按年份预测牛熊的时钟。

### 5.4 名义与实际

D§1405—1420 区分名义 GDP、实际产出、工资与物价。产量增加不保证收入利润增加，名义工资增加也不保证实际购买力改善。跨国比较须说明总量还是增速、币种和价格口径。

## 6. 核心资产九维框架

依据 D§236—249，至少每季度复核：

| 维度 | 研究证据 |
|---|---|
| 政策与监管 | 许可、限制、处罚、规则与政策逆转 |
| 商业模式稳定 | 收入来源、客户、刚需、替代、竞争 |
| 小股东利益 | 披露、稀释、关联交易、并购与资本配置 |
| 财务稳定 | 跨周期利润率、ROE/ROIC、债务和盈利质量 |
| 现金创造 | 经营现金流、维持投入、分红回购与覆盖 |
| 波动性质 | 日常/危机回撤、流动性和相关性 |
| 成长性 | 增长来源、创新、壁垒和新增资本回报 |
| 估值 | 模型、隐含假设、同业与安全边际 |
| 买点 | 风格、趋势、事件、波动和分批方案 |

这是核心资产研究表，不直接适用于所有主题交易。补充建议采用“否决项+分项证据”，真实性、治理、偿债与商业模式崩塌不能被其他高分抵消。未知必须标未知，不由 AI 凭空打分。

“核心无需止损”只能理解为某些投资者不按短期价格机械止损，不能理解为永不卖、无限摊平。核心资格会失效，估值也可能过高。

## 7. 公司估值要贴近生意

D§836—867 用股东/包子铺视角研究：经营者诚信 → 生意为何好 → 竞争能否复制 → 资本投入与分红 → 债务资本效率 → 购买价格。

每个公司都应回答：谁付钱、为何付、钱能否收回、维持生意要再投多少、最后留给股东多少。

商业物业看净租金和经营现金流，零售看自由现金流，半导体看制程产能、利用率、价格、良率和折旧，再转成现金流。不能把某项经营指标当成完整估值公式。

股票要求回报包括无风险利率与风险溢价；每股盈利也受股本变化影响。利率下降未必抵消盈利下滑。

## 9. 外汇、REITs 与新金融

### 9.1 外汇

D§1431—1484 看相对增长、利率、贸易、科技、资本再配置及企业定价权。

人民币本位投资：人民币回报 = (1+外币资产当地回报)×(1+外币兑人民币变动)−1，再扣税费和交易成本。上市地、交易币种、收入与债务币种要分开。

### 9.2 REITs

D§1489—1553 按项目看出租率、租约、客户、租金、融资、杠杆、期限和分派；公路、物流、住宅、办公、酒店对经济敏感度不同。

期限型分派可能含本金回收，不能只比较派息率；FFO 不等于实际现金流，应结合维持投入与可分派金额。原文偏固收定位不等于保本，海外分配规则也不能照搬国内 90%口径。

### 9.3 稳定币与 RWA

D§1555—1611 沿发行、兑换、交易、托管、尽调、分销、链与预言机查收费权与净受益者。可迁移到其他新技术：谁付费，谁受损，谁有壁垒，价值是否已计价？

制度与数字需核验：稳定币储备并非全相同，发行人可中心化；链上转账量不等于实际支付消费；代币和智能合约不自动保证线下法律权利。需看牌照、法域、托管、破产隔离与执行。

## 10. 执行与行为纪律

### 10.1 持仓承受力在买入前解决

D§163—166、271、725 要求计算总预算、最坏损失、资金使用率和持仓规模。补充情景包括价格大跌、相关性上升、收入减少和提前用钱。主观舒服不能代替客观风控。

### 10.2 价格与消息是证据

D§194—234、274—277 讨论强弱阶段、标志 K 线、突破、波动、利好利空的反应。它们需要定义后检验。市场可能错误定价，不能把“市场知道全部信息”理解为事实定律。

### 10.3 四类卖出理由

- 逻辑退出：经营、治理、财务或周期假设实质变化。
- 估值退出：未来预期回报不足。
- 组合减仓：上涨或波动导致风险贡献超限。
- 机会替换：更有吸引力且更适合组合的选择。

依据 D§251—285、386。卖出理由不取决于当前是否浮盈。

### 10.4 网格

D§291—312 讨论存续、价格中枢、保守上下界、低处增量、拉宽尾部、大小网和保留筹码；也承认卖飞、资金效率与下行问题。

需补破网、趋势、失效、现金耗尽、成本和预留资金收益。单网收益不等于策略年化，利润筹码也有机会成本与市场风险。没有绝对“不死”的 ETF，不能无限补仓。

### 10.5 保护与卖方增强不同

D 同时出现尾部保险与卖 put（D§329—333、738—739、774）。买保护性期权与卖 put 风险方向不同；后者附带尾部与保证金压力。IV 高于历史波动不保证卖方盈利。

黄金、长债与期权的保护机制不同，不能无条件替代；黄金没有固定行权保护，通胀冲击中股债可能同跌。

### 10.6 复盘过程而非只看盈亏

D§314—358 要求先模型、再决策、记录当时信息和反应、回看行为模式，不爱上公开观点。复盘区分事实可得性、假设反证、执行纪律、市场暴露和运气；盈利不自动证明方法正确。

## 11. 需要保留而不能强行合并的冲突

| 表述差异 | 研究处理 |
|---|---|
| 不追高 / 好资产立即买 | 区分目标调整、估值与短期情绪交易 |
| 核心越跌越买 / 下行止损 | 区分短期价格与逻辑失效，始终有限额 |

| 长期不择时 / 技术共振 | 区分资产周期性、目的与持有期 |
| 黄金无性价比 / 买前比较 | 黄金仍有价格、机会成本与边际贡献 |
| 低波大配 / 尾部分散失效 | 常态模型外加压力、融资与流动性约束 |

## 12. 数学、定义与推断纠错

1. VaR 是给定期限概率下的损失分位数，不是最大可能亏损；尾部需 ES、压力与流动性分析。VaR 一般不保证次可加。
2. 风险平价不是固定股债比例；历史波动数字需指数、年化、起止与币种口径。
3. 股债比例后“再加黄金”有分母歧义，必须先说明预算或杠杆。
4. 企业价值不能一般化为市值加全部负债减现金；经营负债与有息债务应区分。
5. FCF 需与企业或股权价值匹配，利息、租赁和维持投入等会影响口径；指数依正式方案。
6. 商品成本不是硬底；现金成本、套保、债务、库存与战略行为会改变退出。
7. 工资不是持续通胀的唯一必要条件。
8. 历史发生过不代表风险不会重演，套息拆仓仍可能积累。
9. 无模型的股市最大回撤预测不能变成风险底线。
10. 股债汇三涨三跌不是黄金自动开关。
11. 工增、社零、出口、固投口径不同，不能把增速简单拼成恒等式。
12. 规上样本、可比口径与利润总额都需核对，PPI 不是利润的通用平减指数。
13. 债券除能否偿付，还有久期、通胀、流动性、再投资与币种风险。
14. 保险持仓科目增加不等于全为净买入，需分公允价值、交易、分类和范围变化。
15. 平台月活与付费用户有重叠，不能直接相加当全国渗透率。
16. 药物授权合同总额不等于现金或收入，需概率、时间与折现。
17. 北向披露、指数成分等制度会变，不能假设旧字段继续实时可得。
18. 隐含波动升高可代表恐惧而非贪婪，期权比值要明确成交/持仓、分子分母与期限。

## 14. 下一阶段的具体研究

1. 九维清单做成可核对证据表，先设否决项。
2. 选择一个产业案例走通付费者到仓位的全过程。
3. 复现财报超预期与质量表，查预期样本、可比性与时点。
